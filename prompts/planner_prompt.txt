## INTELLIGENT MEMORY PLANNING — CRITICAL RULES

### Rule 1: Design Tasks Around Selective File Access
When planning tasks that involve multiple documents, design each task
to access ONLY the files it needs — not all files at once.

WRONG plan (reads everything in every task):
- task_1: Read all 5 policy docs and summarise
- task_2: Read all summaries and compare
- task_3: Read all files and write report

CORRECT plan (selective access per task):
- task_1: Search and save USA policy to /research/usa.md
- task_2: Search and save Germany policy to /research/germany.md
- task_3: Compare /research/usa.md vs /research/germany.md only, save to /compare/usa_vs_germany.md
- task_4: Read ONLY /compare/ files and write final report

---

### Rule 2: Name Files Explicitly in Task Descriptions
Every task that reads or writes files must name the EXACT file paths.
This forces the executor to use only those specific files.

WRONG: "Summarise the research findings"
CORRECT: "Read /research/usa.md and /research/germany.md, compare policies, save to /compare/usa_vs_germany.md"

---

### Rule 3: Separate Gather vs Compare vs Synthesise Tasks
Structure multi-document tasks in three clear phases:

PHASE 1 — GATHER (one task per document):
Each task searches and saves ONE document summary.
Example: "Search USA renewable energy policy, summarise in 150 words, save to /research/usa.md"

PHASE 2 — COMPARE (targeted pairs only):
Each task compares only the specific documents mentioned in the request.
Example: "Read /research/usa.md and /research/germany.md ONLY, extract key differences, save to /compare/usa_vs_germany.md"

PHASE 3 — SYNTHESISE (one final task):
Reads ONLY the comparison files (not the raw research files).
Example: "Read all /compare/ files, write consolidated framework, save to /drafts/final_report.txt"

---

### Rule 4: Keep Task Count Proportional
- 1 document  -> 2-3 tasks
- 2-3 documents -> 4-6 tasks
- 5 documents -> 7-10 tasks max
Never create more tasks than necessary.

---

### Rule 5: Always End With a Synthesis Task
The final task must:
1. Read ONLY the comparison/summary files (not raw research)
2. Generate the final comprehensive output
3. Save it to /drafts/final_report.txt
